## 📋 测试前准备

### 1. 检查工具安装

```bash
# 检查必需工具
which nmap whatweb nuclei afrog nikto zap-cli sqlmap

# 如果缺少，安装工具
# Nuclei
go get -u github.com/projectdiscovery/nuclei/v3/cmd/nuclei

# Afrog
go get -u github.com/zan8in/afrog

# Nikto
sudo apt-get install nikto

# ZAP-CLI
pip3 install zap-cli

# SQLMap
git clone --depth 1 https://github.com/sqlmapproject/sqlmap.git ~/tools/sqlmap
ln -s ~/tools/sqlmap/sqlmap.py /usr/local/bin/sqlmap
```

### 2. 检查 Python 依赖

```bash
pip3 install psutil pydantic aiohttp asyncio
```

### 3. 检查目标可达性

```bash
# 测试目标是否可访问
curl -I http://demo.testfire.net

# 或使用其他目标
curl -I http://your-target.com
```

## 🛠️ 故障排查

### 问题 1: 模块导入失败

**错误**: `ModuleNotFoundError: No module named 'core'`

**解决**:
```bash
export PYTHONPATH="$HOME/.openclaw/workspace/skills/advanced-pentester-v2/intelligent-test-orchestrator:$PYTHONPATH"
```

### 问题 2: 工具未找到

**错误**: `FileNotFoundError: [Errno 2] No such file or directory: 'nuclei'`

**解决**:
```bash
# 安装缺失工具
which nuclei afrog nikto zap-cli sqlmap

# 根据缺失情况安装
```

### 问题 3: 连接超时

**错误**: `Connection timeout`

**解决**:
```bash
# 检查目标可达性
curl -I http://demo.testfire.net

# 检查网络
ping demo.testfire.net

# 更换目标
python3 test/test_integration.py --target http://other-target.com
```

### 问题 4: 测试超时

**解决**:
```bash
# 增加超时时间
python3 test/test_integration.py --timeout 1800
```
