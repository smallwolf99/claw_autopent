## 💡 实际效果差异

### 1. 标题样式

**纯 Markdown：**
- 默认字体大小
- 无特殊效果
- 黑色文字

**CSS 美化：**
- 大号字体（3em）
- 藏青色渐变 + 双层阴影
- 字间距加宽

### 2. 表格样式

**纯 Markdown：**
- 简单边框
- 灰色背景（表头）
- 直角边框

**CSS 美化：**
- 毛玻璃效果（半透明）
- 圆角边框（12px）
- 轻阴影效果
- 渐变背景

### 3. 引用块（警告）

**纯 Markdown：**
- 灰色左边框
- 灰色文字
- 简单样式

**CSS 美化：**
- 红色背景（10% 透明度）
- 红色左边框（4px）
- 红色文字
- 居中对齐
- 圆角效果

### 4. 背景

**纯 Markdown：**
- 白色背景
- 无装饰

**CSS 美化：**
- 蓝紫渐变背景
- 专业质感

```css
.cover-page {
    background: linear-gradient(135deg, #e8eaf6 0%, #e3f2fd 50%, #ede7f6 100%);

    text-shadow: 2px 2px 4px rgba(26, 35, 50, 0.3);
}

.cover-page table {
    background: rgba(255, 255, 255, 0.7);
    border-radius: 12px;
}
```
